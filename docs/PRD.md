# PRD - Wiloo Mobile App

## Vision

Wiloo est une application RH et pointage intelligent pour les entreprises, avec une experience mobile Android, iOS et desktop.

## Utilisateurs

- Employes
- Managers
- Administrateurs RH
- Dirigeants

## V1

1. Terminal de pointage
   - PIN
   - QR code
   - verification visage
   - arrivee, debut pause, retour pause, depart

2. Espace employe
   - historique de presence
   - demandes de conges
   - profil

3. Espace manager
   - presence equipe
   - validations
   - alertes

4. Administration RH
   - employes
   - presence
   - conges
   - preparation paie

## Contraintes

- Backend NestJS existant.
- Auth Better Auth existante.
- Pas de systeme JWT parallele.
- Roles et scopes respectes.
- API comme source de verite.
